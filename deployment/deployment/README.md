#Steps
1. Download the GitHub repository.
2. Open a terminal in the `deployment` folder.
3. Install the required libraries:
Streamlit
TensorFlow
NLTK
NumPy

4. Run the Streamlit application:
5. Open the local URL displayed in the terminal to use Researchly.

#Files needed
The deployment folder contains:
app.py – Streamlit application.
researchly_model.keras – Trained LSTM Dropout model.
tokenizer.pkl – Saved text tokenizer.
encoder.pkl – Saved label encoder.
max_len.pkl – Saved maximum sequence length.
requirements.txt – Required Python libraries
